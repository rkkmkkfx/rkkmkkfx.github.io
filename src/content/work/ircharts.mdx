## The work

IRCharts needed a web presence that could carry serious financial data without making every visitor feel like an analyst. I shaped the interface around clear visual hierarchy, reusable components, and a system that could support both the marketing site and embedded widgets.

## Technical note

The interesting constraint was consistency: every surface had to communicate the same model of the data. React and TypeScript gave the UI a shared vocabulary while CSS Modules kept visual rules close to the components they described.
